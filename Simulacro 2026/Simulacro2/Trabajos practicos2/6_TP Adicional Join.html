Ejercicio 1. Libros y sus autores

Mostrar los libros indicando título, género, año de publicación, nombre y apellido del autor y nacionalidad. Incluir únicamente los libros publicados antes de 1980 y ordenar desde el más antiguo al más reciente.

02

Ejercicio 2. Préstamos realizados

Mostrar los préstamos realizados indicando id del préstamo, nombre completo del socio en una sola columna llamada socio, título del libro, fecha de préstamo, fecha de devolución y estado. Construir el nombre completo utilizando CONCAT. Ordenar desde el préstamo más reciente al más antiguo.

03

Ejercicio 3. Préstamos de determinados géneros

Mostrar los préstamos correspondientes a libros de género Novela o Distopia, indicando nombre y apellido del socio, título del libro, género, nombre y apellido del autor, fecha de préstamo y estado. Mostrar únicamente los primeros 5 resultados ordenados por fecha de préstamo de forma descendente.

04

Ejercicio 4. Préstamos recientes

Mostrar los préstamos realizados en los últimos 30 días tomando como referencia la fecha actual. Indicar nombre completo del socio, título del libro, nombre completo del autor, fecha de préstamo y estado. Utilizar una función de fecha para determinar automáticamente desde qué día deben considerarse los préstamos y ordenar desde el más reciente al más antiguo.

05

Ejercicio 5. Todos los socios y sus préstamos

Mostrar todos los socios registrados, hayan realizado préstamos o no. Indicar nombre completo del socio, email, estado, título del libro, fecha de préstamo y estado del préstamo cuando corresponda. Ordenar alfabéticamente por apellido y nombre del socio.

06

Ejercicio 6. Autores y libros publicados

Mostrar todos los autores registrados, junto con los libros que tengan asociados. Deben aparecer también los autores que todavía no tengan ningún libro cargado. Indicar nombre completo del autor, nacionalidad, título y género del libro. Cuando un autor no tenga libros asociados, mostrar un texto descriptivo en lugar de valores NULL. Ordenar alfabéticamente por apellido y nombre del autor.

07

Ejercicio 7. Libros nunca prestados

Mostrar únicamente los libros que nunca hayan sido prestados. Indicar título, género, año de publicación, nombre completo del autor y disponibilidad. Ordenar alfabéticamente por título.

08

Ejercicio 8. Préstamos pendientes

Mostrar los socios activos que tengan préstamos cuyo estado sea Activo o Vencido y para los cuales hayan transcurrido más de 15 días desde la fecha del préstamo. Indicar nombre completo del socio, email, título del libro, nombre completo del autor, fecha de préstamo, estado y cantidad de días transcurridos. Ordenar de mayor a menor según los días transcurridos.

09

Ejercicio 9. Autores vinculados a préstamos

Mostrar, sin repetir, los autores cuyos libros hayan sido prestados a socios activos. Indicar nombre completo del autor y nacionalidad. Ordenar alfabéticamente por el nombre completo del autor.

10

Ejercicio 10. Búsqueda de libros disponibles

Mostrar los libros que se encuentren disponibles, cuyo género sea Novela y cuyo título contenga la letra a. Indicar título, género, año de publicación y nombre completo del autor. Mostrar únicamente los primeros 3 resultados, ordenados desde el libro más reciente al más antiguo.

Script de creación

Ejecutar primero este bloque para crear la base de datos, las tablas y sus relaciones.

Creación de la base y las tablas
CREATE DATABASE bdd1_tp_joins_biblioteca
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_0900_ai_ci;

USE bdd1_tp_joins_biblioteca;

-- =========================================================
-- TABLA: socios
-- =========================================================

CREATE TABLE socios (
    id_socio INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(50) NOT NULL,
    apellido VARCHAR(50) NOT NULL,
    email VARCHAR(100) NOT NULL UNIQUE,
    fecha_alta DATE NOT NULL,
    estado ENUM('Activo', 'Inactivo') NOT NULL DEFAULT 'Activo'
);

-- =========================================================
-- TABLA: autores
-- Para este práctico se asume que cada libro tiene un único autor.
-- =========================================================

CREATE TABLE autores (
    id_autor INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(50) NOT NULL,
    apellido VARCHAR(50) NOT NULL,
    nacionalidad VARCHAR(50) NOT NULL
);

-- =========================================================
-- TABLA: libros
-- =========================================================

CREATE TABLE libros (
    id_libro INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    titulo VARCHAR(120) NOT NULL,
    genero VARCHAR(50) NOT NULL,
    anio_publicacion SMALLINT UNSIGNED NOT NULL,
    disponible BOOLEAN NOT NULL DEFAULT TRUE,
    id_autor INT UNSIGNED NOT NULL,

    CONSTRAINT fk_libros_autores
        FOREIGN KEY (id_autor)
        REFERENCES autores (id_autor)
        ON UPDATE CASCADE
        ON DELETE RESTRICT
);

-- =========================================================
-- TABLA: prestamos
-- =========================================================

CREATE TABLE prestamos (
    id_prestamo INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    id_socio INT UNSIGNED NOT NULL,
    id_libro INT UNSIGNED NOT NULL,
    fecha_prestamo DATE NOT NULL,
    fecha_devolucion DATE NULL,
    estado ENUM('Activo', 'Devuelto', 'Vencido') NOT NULL,

    CONSTRAINT fk_prestamos_socios
        FOREIGN KEY (id_socio)
        REFERENCES socios (id_socio)
        ON UPDATE CASCADE
        ON DELETE RESTRICT,

    CONSTRAINT fk_prestamos_libros
        FOREIGN KEY (id_libro)
        REFERENCES libros (id_libro)
        ON UPDATE CASCADE
        ON DELETE RESTRICT
);
