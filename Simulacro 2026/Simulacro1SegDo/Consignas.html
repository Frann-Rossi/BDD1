01 · Consigna general

Forma de trabajo

Resolver las consignas utilizando MySQL 8. Antes de comenzar, ejecutar el script completo de la base de datos.

  • Escribir las consultas en el orden propuesto.
  • En los ejercicios de vistas, respetar los nombres indicados.
  • En los ejercicios combinados, utilizar el recurso solicitado en cada etapa.
  • Verificar los resultados antes de considerar finalizado cada ejercicio.
Importante: este TP es adicional. Las situaciones fueron planteadas para no repetir las consignas principales de los trabajos anteriores.
02 · Base de datos

Comercializadora tecnológica

La base representa una empresa con sucursales, vendedores, clientes, categorías, productos y ventas.

TablaFunción
sucursalesSucursales y ciudades.
vendedoresVendedores asignados a sucursales.
clientesClientes particulares y empresas.
categoriasCategorías comerciales.
productosProductos, precio actual y estado.
ventasCabecera de cada operación.
detalle_ventasProductos, cantidades y precios vendidos.
Script completo de creación e inserción
DROP DATABASE IF EXISTS tp_integrador_consultas;
CREATE DATABASE tp_integrador_consultas
CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;

USE tp_integrador_consultas;

CREATE TABLE sucursales (
    id_sucursal INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(80) NOT NULL,
    ciudad VARCHAR(80) NOT NULL
);

CREATE TABLE vendedores (
    id_vendedor INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    id_sucursal INT NOT NULL,
    fecha_ingreso DATE NOT NULL,
    FOREIGN KEY (id_sucursal) REFERENCES sucursales(id_sucursal)
);

CREATE TABLE clientes (
    id_cliente INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    ciudad VARCHAR(80) NOT NULL,
    tipo VARCHAR(20) NOT NULL
);

CREATE TABLE categorias (
    id_categoria INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(80) NOT NULL UNIQUE
);

CREATE TABLE productos (
    id_producto INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    id_categoria INT NOT NULL,
    precio DECIMAL(10,2) NOT NULL,
    activo TINYINT(1) NOT NULL DEFAULT 1,
    FOREIGN KEY (id_categoria) REFERENCES categorias(id_categoria)
);

CREATE TABLE ventas (
    id_venta INT AUTO_INCREMENT PRIMARY KEY,
    fecha DATE NOT NULL,
    id_cliente INT NOT NULL,
    id_vendedor INT NOT NULL,
    FOREIGN KEY (id_cliente) REFERENCES clientes(id_cliente),
    FOREIGN KEY (id_vendedor) REFERENCES vendedores(id_vendedor)
);

CREATE TABLE detalle_ventas (
    id_detalle INT AUTO_INCREMENT PRIMARY KEY,
    id_venta INT NOT NULL,
    id_producto INT NOT NULL,
    cantidad INT NOT NULL,
    precio_unitario DECIMAL(10,2) NOT NULL,
    FOREIGN KEY (id_venta) REFERENCES ventas(id_venta),
    FOREIGN KEY (id_producto) REFERENCES productos(id_producto)
);

03 · CTE

Bloque A — Expresiones comunes de tabla

Resolver mediante una o más CTE.

CTEEjercicio 1

Clientes atendidos por más de un vendedor

Crear una CTE que obtenga, para cada cliente, la cantidad de vendedores distintos que lo atendieron durante 2026. En la consulta principal, mostrar únicamente los clientes que fueron atendidos por más de un vendedor, incluyendo nombre del cliente y cantidad de vendedores.

CTEEjercicio 2

Importe vendido por sucursal

Crear una CTE que calcule el importe total vendido por cada sucursal a partir de ventas y detalle_ventas. En la consulta principal, mostrar las sucursales ordenadas de mayor a menor importe y agregar el nombre de la ciudad.

CTEEjercicio 3

Productos con movimiento en varios meses

Crear una CTE que determine en cuántos meses diferentes fue vendido cada producto durante 2026. Mostrar únicamente los productos que tuvieron ventas en al menos dos meses distintos.

CTEEjercicio 4

Dos etapas de resumen

Resolver utilizando dos CTE. La primera debe calcular el importe total de cada venta. La segunda debe resumir esos importes por vendedor. En la consulta principal, mostrar nombre del vendedor, sucursal y total vendido, ordenando de mayor a menor.

04 · Vistas

Bloque B — Vistas

Crear y reutilizar vistas sobre la nueva base.

VISTAEjercicio 5

Catálogo comercial activo

Crear una vista llamada v_catalogo_activo que reúna id_producto, producto, categoría, precio y estado activo, pero que exponga solamente los productos actualmente activos. Luego consultar la vista mostrando únicamente producto, categoría y precio, ordenados por categoría y nombre.

VISTAEjercicio 6

Detalle comercial de ventas

Crear una vista v_detalle_comercial que reúna en una sola estructura: id_venta, fecha, cliente, vendedor, sucursal, producto, categoría, cantidad, precio_unitario e importe de línea (cantidad × precio_unitario). Realizar luego una consulta sobre la vista para mostrar las operaciones de una sucursal elegida.

VISTAEjercicio 7

Clientes empresa

Crear una vista v_clientes_empresa que muestre únicamente id_cliente, nombre y ciudad de los clientes cuyo tipo sea EMPRESA. Luego utilizar la vista para listar cuántos clientes empresa hay por ciudad.

VISTAEjercicio 8

Resumen de vendedores

Crear una vista v_resumen_vendedores que muestre, por vendedor, cantidad de ventas realizadas e importe total vendido. Luego consultar esa vista para obtener los tres vendedores con mayor importe acumulado.

05 · Combinación

Bloque C — CTE + Vistas

Utilizar una vista como origen y una CTE para organizar un procesamiento temporal.

CTE + VISTAEjercicio 9

Resumen temporal sobre catálogo

Utilizando v_catalogo_activo, crear una CTE que agrupe los productos activos por categoría e informe cantidad de productos y precio máximo. En la consulta principal, mostrar únicamente las categorías que tengan dos o más productos activos.

CTE + VISTAEjercicio 10

Ventas por cliente a partir de una vista

Utilizando v_detalle_comercial como origen, crear una CTE que calcule por cliente: cantidad de ventas distintas e importe total comprado. Mostrar los resultados ordenados por importe total de mayor a menor.

CTE + VISTAEjercicio 11

Comparación entre sucursales

A partir de v_detalle_comercial, crear una CTE que calcule el importe total vendido por sucursal. Utilizar luego esa CTE para mostrar cada sucursal junto con su total y ordenar el resultado de mayor a menor. No crear una nueva vista para este resumen.

CTE + VISTAEjercicio 12

Productos destacados por categoría

Usando v_detalle_comercial, crear una CTE que acumule la cantidad total vendida por producto. En la consulta principal, mostrar producto, categoría y cantidad total vendida para aquellos productos que hayan acumulado al menos 2 unidades.

06 · Integración

Bloque D — Subconsultas con Vistas y CTE

Combinar contenidos sin aumentar innecesariamente la complejidad.

SUBQUERY + VISTAEjercicio 13

Vendedores por encima del promedio

Utilizando v_resumen_vendedores, obtener los vendedores cuyo importe total vendido sea superior al importe promedio calculado sobre la propia vista. La comparación final debe resolverse mediante una subconsulta escalar.

SUBQUERY + VISTAEjercicio 14

Productos activos aún no vendidos

Utilizando v_catalogo_activo, mostrar los productos activos que no aparezcan en ningún registro de detalle_ventas. Resolver la condición mediante NOT EXISTS.

SUBQUERY + CTEEjercicio 15

Clientes con compras superiores al promedio

Crear una CTE que calcule el total comprado por cada cliente. En la consulta principal, mostrar solamente los clientes cuyo total sea superior al promedio de los totales obtenidos en la propia CTE. La comparación debe resolverse mediante una subconsulta.

INTEGRADOREjercicio 16

Vista + CTE + subconsulta

Utilizar v_detalle_comercial como origen. Crear una CTE que calcule el total vendido por categoría. Luego mostrar únicamente las categorías cuyo total vendido sea superior al promedio de los totales por categoría. La comparación final debe realizarse mediante una subconsulta sobre la CTE.

07 · Operadores de subconsulta

Bloque E — EXISTS, ANY / SOME y ALL

Ejercicios adicionales para practicar operadores de subconsulta en combinación con tablas, vistas y CTE.

EXISTSEjercicio 17

Clientes con compras de productos de Redes

Mostrar los clientes que hayan realizado al menos una compra que incluya productos de la categoría Redes.

La consulta debe resolverse utilizando EXISTS.

EXISTS + VISTAEjercicio 18

Vendedores con ventas destacadas

Utilizando la vista v_detalle_comercial, mostrar los vendedores que hayan participado al menos una vez en una venta cuyo importe de línea sea superior a 300000.

La condición debe resolverse utilizando EXISTS.

ALLEjercicio 19

Productos por encima de toda una categoría

Mostrar los productos activos cuyo precio sea mayor que el precio de todos los productos pertenecientes a la categoría Oficina.

La comparación debe resolverse utilizando ALL.

ANY / SOMEEjercicio 20

Productos por debajo de alguno de Computación

Mostrar los productos activos cuyo precio sea menor que el precio de al menos uno de los productos pertenecientes a la categoría Computacion.

Resolver utilizando ANY o SOME.

CTE + ALLEjercicio 21

Vendedores por encima de todos los de Puerto

Crear una CTE que obtenga el total vendido por cada vendedor.

Luego mostrar los vendedores cuyo total vendido sea mayor que todos los totales correspondientes a los vendedores de la sucursal Puerto.

La comparación final debe resolverse utilizando ALL.

VISTA + ANYEjercicio 22

Comparación entre vendedores

Utilizando v_resumen_vendedores, mostrar los vendedores cuyo total vendido sea mayor que el total vendido de al menos uno de los vendedores con 3 o más ventas.

La comparación debe resolverse utilizando ANY o SOME.

08 · Entrega

Antes de finalizar

  • Guardar las consultas en un único archivo .sql.
  • Separar los bloques con comentarios.
  • Incluir las sentencias CREATE VIEW utilizadas.
  • Comprobar que la solución pueda ejecutarse sobre una base recién creada.
  • Poder explicar qué papel cumple la CTE, la vista o la subconsulta en los ejercicios integradores.
